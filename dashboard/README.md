# Дашборд диспетчера · Предиктор задержек

Дашборд обеспечивает визуализацию и мониторинг в реальном времени состояния транспортной сети, предсказывая задержки (ML-сервис) и предлагая диспетчеру меры по реагированию. 

Интерфейс работает полностью автономно (с локальной офлайн-картой) и включает три основных экрана:
1. **Диспетчерская**: Карта, алерты, карточки ТС и возможность симуляции мер («+ Доп. автобус», «Сократить стоянки»).
2. **Аналитика**: Оценка качества прогноза (ошибки, метрики горизонта 10-15 мин), производительность системы.
3. **Журнал**: История всех инцидентов, прогнозы и события системы.

---

## Запуск (Режим LIVE)

Вся система поднимается вместе с Backend и ML-сервисом одной командой из корня репозитория:
```bash
docker compose up --build -d
```
После запуска дашборд будет доступен по адресу: **http://localhost:18090**.

*(Для работы без связи с Backend предусмотрен встроенный исторический REPLAY-режим, который включится автоматически, если API недоступен).*

## Сценарий демо для жюри (~2 мин)

1. **Диспетчерская.** В шапке видна сводка проблемных маршрутов. На карте красным выделены ТС с инцидентами.
2. **Внимание к деталям.** Слева панель «Требуют внимания»: кто опаздывает, почему, и рекомендация.
3. **Карточка ТС.** При клике на ТС открывается график времени прибытия с прогнозом на 10–15 минут вперёд. Здесь же можно протестировать "Меры диспетчера" (добавить автобус, сократить стоянку).
4. **Аналитика.** Покажите раздел с метриками ошибки, качеством улавливания задержек и задержкой обработки данных. Во вкладке «Демо» в шапке можно нажать «Обрыв связи», чтобы продемонстрировать устойчивость системы (fallback-сценарии).

## Ключевые возможности

* **Офлайн-карта и Map Matching**: Данные подложки (OSM) скачиваются при сборке Docker и загружаются локально, обеспечивая моментальную отрисовку без задержек.
* **Меры диспетчера (What-if)**: 
  * *Доп. автобус* — симуляция выпуска резервного рейса и пересчёт опозданий.
  * *Сократить стоянки* — симуляция сокращения времени простоя на остановках для компенсации задержки.
* **Fallbacks**: При отключении ML-модели или обрыве связи дашборд продолжает работать, визуально информируя диспетчера о статусе системы.
