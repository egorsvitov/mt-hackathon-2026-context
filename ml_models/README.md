# ML-эксперименты

Каждая модель хранится в отдельной пронумерованной папке вместе с воспроизводимым кодом,
зависимостями, тестами, сохранённым model bundle и отчётом. Кэши признаков и виртуальные
окружения не добавляются в Git.
