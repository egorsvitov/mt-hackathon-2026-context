Инфраструктура
--------------
Решение состоит из:

* **Backend (FastAPI)** — пайплайн обработки телеметрии, расчет признаков.
* **ML Service (CatBoost)** — модель предсказания времени прибытия (состояние: разработка).
* **Dashboard (Nginx + JS)** — визуализация на карте.
